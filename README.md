# Dominican Books

Crea la aplicación web para un ERP contable de República Dominicana, iniciando con el módulo de Facturación con soporte para NCF/e-CF, ITBIS, gestión de clientes e items. Incluye la estructura y backend (Edge Functions) preparado para conectarse a una base de datos MySQL/MariaDB externa mediante variables de entorno seguras.
